# MOMENT — 초대장 제작기 · Build 8

일반 행사(생일·돌잔치·집들이·모임·기념일)를 위한 모바일 초대장 메이커입니다.

## 디자인
- BASIC 4종: Build 5부터 이어진 무료 디자인으로 고화질 PNG 저장 가능.
- PREMIUM 6종: 사용자가 제공한 독자적인 PNG를 바탕으로 한 워터마크 미리보기.
- 프리미엄 배경은 각각 독립적인 사진과 문구 레이아웃을 사용합니다.

## Build 8 변경
- 사진틀 크기 75~115% 조절 기능(프리미엄, 사진 첨부 시 표시)
- 일부 디자인에서 표시되지 않던 초대 문구와 상세 정보를 추가
- 제목이 긴 경우 줄바꿈·가독성 개선
- 기존 BASIC 4종 이미지 출력 로직은 변경하지 않음

## GitHub Pages
Settings → Pages → Deploy from a branch → main / (root)

## 설문
`config.js`에 본인이 생성한 Formspree 주소를 입력해야 설문 전송이 활성화됩니다.
개인 사진과 초대장 편집 데이터는 서버로 업로드되지 않도록 설계됐습니다.

## 판매 관련 주의
현재 결제 기능은 없습니다. 가격 9,900원은 시험 가정입니다.
공개판에서는 프리미엄 고화질 저장을 UI에서 제한하지만, 이것은 보안용 유료 권한 관리가 아닙니다.
실제 유료 판매 전에는 결제 검증 서버·구매 권한 확인·원본 파일 보호 및 전송 기능이 필요합니다.
고화질 프리미엄 원본과 내부 검수용 HTML을 공개 저장소에 올리지 마세요.
