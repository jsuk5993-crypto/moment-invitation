# Build 32 테스트 취소 버튼 — 폐기됨 (Build 33)

MOMENT는 **다운로드형 디지털 초대장** 상품입니다. 결제 후 바로 원본/PNG를 받고 버튼 한 번으로 임의 전액 취소할 수 있게 하면 이미 사용한 디자인을 무상으로 보유할 수 있습니다.

따라서 이전 Build 32에서 추가한
- 프리미엄 카드의 `내 테스트 결제 취소 · 권한 회수 검증` 버튼
- 일반 구매자 라이선스로 호출 가능한 `POST /api/test-cancel`
을 Build 33에서 **모두 제거**했습니다. 기존 고객의 다운로드, 프리미엄 잠금 해제, 재접속 유지 기능은 변경하지 않습니다.

## 남겨야 하는 환불 처리
- 판매자는 고객 문의 및 관련 법률에 따라 정당한 환불 사유를 심사합니다.
- 승인 오류, 중복 결제, 콘텐츠 제공 불가, 상품 표시와 다른 결과 등의 경우 법적 환불 의무를 검토합니다.
- 토스 사업자 관리자 화면에서 적법하게 환불을 처리하면, 기존 `/api/license?verify=1`, `/api/toss-webhook`, 관리자용 `/api/reconcile`의 **토스 서버 재검증** 후 D1 구매 라이선스를 회수합니다.
- 고객은 토스 환불을 직접 API 호출해 실행할 수 없습니다.
- **해당 기능은 아직 라이브 판매가 아니므로 환불약관과 고객문의 채널을 실제 출시 전 검토해야 합니다.**
