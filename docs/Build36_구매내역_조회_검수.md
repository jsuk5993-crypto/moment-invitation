# MOMENT Build 36 — 구매내역 조회 및 안전한 고객지원 준비

## 구현 내용
- 동일 브라우저의 구매 라이선스가 확인되거나 1회용 복원코드로 권한을 옮긴 구매자에게만 **내 구매내역** 표시
- 결제내역은 Worker GET /api/purchases/me에서 **Bearer 토큰으로만** 조회, 주문번호를 입력하거나 URL을 바꾸는 것으로 다른 사람의 내역을 볼 수 없음
- 토스의 실제 DONE 상태를 매 조회 시 검증하며 환불된 주문은 401 응답과 이용권 회수, 일시적 토스 장애 시 503 응답과 기존 권한 보존
- 응답은 주문번호, 9,900원, 구매일시, 상품명, 프리미엄 디자인 수량 등 최소 정보만 표시
- 토스 paymentKey, checkoutSecret, 라이선스 토큰, 복원코드, 고객 개인정보는 API 응답·화면에 포함되지 않음
- 신규 구매 결제 중지 중에도 구매내역과 기존 권한 조회 가능
- 기존 복원코드 발급·재발급·복원 기능과 환불 상태 검증 유지

## 직접 확인
1. Cloudflare TEST 개발 브랜치 배포 후 /api/payment-setup에서 build:36 확인
2. 구매 전 프리미엄 카드에서 '내 구매내역'이 숨김인지 확인
3. 구매한 기존 브라우저에서 주문번호·구매일시·9,900원 확인
4. 다른 기기에서 Build35 복원코드를 사용한 후 구매내역이 표시되는지 확인
5. 유효한 토큰 없이 GET /api/purchases/me 호출 시 401인지 확인
6. 테스트에서 판매자가 취소 처리한 구매는 복원과 구매내역 모두 차단되는지 확인

## 아직 정식 판매 기능이 아닌 이유
- 실제 고객센터/이메일 인증 및 소유권 확인 절차가 없어 **주문번호만으로 구매 권한을 다시 발급할 수 없음**
- '문의 시 주문번호 준비'는 안내일 뿐, 자동 고객지원 접수나 전자 영수증 발송을 뜻하지 않음
- 분실 시 복구 가능한 안전한 신원 인증, 거래명세서 교부 및 고객 문의 채널은 추후 구현해야 함
- 상업용 판매 전 사업자 고지·개인정보/전자상거래 준수·고객지원·실제 토스 라이브 심사는 여전히 필요
- 공개 main 브랜치는 변경하지 않으며 TEST 결제만 활성화
