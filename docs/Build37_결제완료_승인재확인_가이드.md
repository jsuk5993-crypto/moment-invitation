# MOMENT Build37 — 결제 완료 후 권한이 안 보이는 문제를 위한 안전한 재확인

- 원인 가능성: 토스 결제 리다이렉트 뒤 페이지 이동/통신 오류로 승인 결과 확인 단계가 완료되지 않거나, 정상 승인된 구매 토큰 이후 이미지 활성화가 실패할 수 있습니다. 사용자 개별 오류 원인은 별도 화면 확인이 필요합니다.
- 결제 콜백이 있는 브라우저 세션에만 기존 orderId/paymentKey 저장. 결제 키는 화면·로그·외부 링크에 표시하지 않습니다.
- 같은 브라우저 PREMIUM 카드의 [기존 결제 승인 다시 확인] 버튼이 동일한 orderId/paymentKey/checkoutSecret로 기존 POST /api/confirm 재호출. 새 주문 생성 및 새 결제창 호출 없음.
- 성공한 경우에만 기존 구매 라이선스 저장 및 프리미엄 이미지 활성화. 이미 유효한 구매자는 종전 복원 흐름을 그대로 사용.
- 서버는 paid 주문의 재확인에서도 토스 결제 상태를 독립적으로 재조회하고, 취소/환불 또는 조회 장애 시 새 이용권 발급 금지.
- 1시간을 초과한 세션 또는 callback/checkout proof가 없는 경우 자동 승인 재확인 불가. 이때 다시 결제하지 말고 고객 지원을 받아야 하며, 운영 전에는 신원확인 기반 장기 구매복원 설계 필요.
- 기존 구매자에게 실제 청구가 발생하지 않는 TEST 결제 전용 기능. 공개 main/LIVE 결제 모드 불변.
