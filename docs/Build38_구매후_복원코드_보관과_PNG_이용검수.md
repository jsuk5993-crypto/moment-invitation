# MOMENT Build 38 — 구매 완료 후 복원코드 안전 보관 / 프리미엄 PNG 이용 안내 (TEST 전용)

## 변경 사항
- 본인 구매 권한이 확인되고 프리미엄 6종의 원본 이미지가 실제로 전송·디코딩되어 활성화된 경우에만 '프리미엄 원본 준비 완료' 표시
- 6/6 배경 확인 후 기존 초대장 편집기로 가는 버튼 제공; 이 버튼 자체가 PNG 파일을 저장하는 것은 아닙니다. 편집기에서 프리미엄 테마를 고르고 사용자 정보를 입력해야 PNG 2장 저장이 가능합니다.
- 1회용 복원코드를 발급하거나 새 기기에서 사용한 후 받은 **다음 코드**를 '복원코드 TXT 파일로 저장' 버튼으로 직접 내려받을 수 있습니다.
- 파일 내용은 브라우저에서만 생성하며 서버에 복원코드를 업로드하지 않습니다. 버튼을 누르지 않으면 자동으로 파일 저장하지 않습니다.
- 민감한 복원코드 파일은 개인 소유 기기에만 보관하고 공유, 공개 저장소 업로드, 메시지 전송을 하지 않도록 안내합니다.
- 복원코드 원문은 기존 정책대로 서버에 보관되지 않으며, D1에는 해시값만 저장됩니다. 재발급하거나 사용한 코드는 무효화됩니다.
- 기존 라이선스 발급, 토스 결제 상태 재확인, 취소/환불 권한 회수, 공개 사이트 메인 브랜치 유지 규칙은 변경하지 않았습니다.

## 수동 TEST 검수
1. 구매 완료한 같은 브라우저에서 프리미엄 카드에 '프리미엄 이용 중', '프리미엄 원본 준비 완료'와 '6/6종'이 표시되는지 확인합니다.
2. '초대장 편집기로 이동 · PNG 2장 저장하기' 버튼을 눌러 #studio4로 이동합니다.
3. 프리미엄 테마를 선택하고 실제로 다운로드 버튼을 눌러 두 장의 PNG 파일이 생성되는지 확인합니다. 자동 테스트는 파일의 실제 기기 저장 동작을 보장하지 않습니다.
4. 기존 구매 화면에서 '1회용 복원코드 발급'을 누르고, TXT 저장 버튼으로 파일이 저장되는지 확인합니다.
5. 파일 안의 64자리 코드는 절대로 GitHub/ChatGPT/고객지원 채팅에 공유하지 않습니다.
6. 별도의 시크릿 창에서 그 코드를 사용해 구매 권한을 이전한 후, **새 코드**를 다시 TXT로 저장합니다. 기존 코드와 원래 기기 라이선스는 무효화되어야 합니다.
7. 프리미엄 배경 전송이 실패할 경우 안내 카드가 완료 상태를 표시하지 않아야 합니다. 새 결제는 하지 않습니다.

## 제한 및 다음 우선순위
- 파일 저장 방식은 모바일 브라우저별로 다를 수 있습니다. 저장이 실패하면 '복원코드 복사'로 수동 보관합니다.
- TXT 파일은 민감한 이전용 비밀입니다. 파일을 가진 사람은 구매 권한을 옮길 수 있으니 특별히 보호해야 합니다.
- 파일을 잃어버리고 원래 기기까지 접근할 수 없다면 자동 복구는 현재 불가능합니다. 구매자 이메일 인증 또는 안전한 고객지원 확인 흐름은 정식 판매 전 별도로 개발해야 합니다.
- 실제 고객 개인정보 수집/이메일 전송/결제 라이브 활성화는 이 Build에서 수행하지 않습니다.
