## 결제 서비스 공식 자료
- 토스페이먼츠 링크페이: https://docs.tosspayments.com/guides/v2/linkpay — 별도 계약 필요, 노코드 결제 링크.
- 토스페이먼츠 결제 흐름: https://docs.tosspayments.com/guides/v2/get-started/payment-flow — 서버 승인, 주문번호·금액 검증 필수.
- 페이플: https://payple.kr/onboarding/ — 사업자등록 필수, 가입비 22만원, 국내 카드 1.0~2.9% 안내(실제 계약별 변동).
- 크몽 개인 전문가 인증: https://support.kmong.com/hc/ko/articles/35271260624153 — 사업자 미등록 프리랜서 인증 가능. 디지털 파일 자동 전달 여부는 상품 등록 시 확인 필요.
- 정부24: https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=11300000006 — 통신판매업 신고 안내.

## 추천 순서
1. 유료 결제 없이 현재 사이트에서 구매 의사·가격 수용도를 확인.
2. 구매자용 오프라인 HTML 상품을 판매 플랫폼에 올릴 수 있는지 심사/약관 확인, 첫 고객 실험.
3. 직접 판매 필요성이 확인되면 사업자등록과 통신판매업 신고 해당 여부를 확인 후 PG 계약 조건 검토.
4. 자체 결제는 서버 측 주문 기록·금액 검증·승인 및 결제 완료 후 안전한 다운로드 토큰 제공 구조로 구축.
5. 실제 매출과 비용이 검증되기 전에는 결제 서버 구축 또는 PG 가입비 지출을 보류.
