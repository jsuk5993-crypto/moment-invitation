# MOMENT Build 39 — 프리미엄 PNG 2장 ZIP 저장 안정성 검수

## 무엇을 바꿨나
- 1장 및 2장 PNG를 저장하기 전에 PNG 시그니처, IHDR, 1080×1350 크기, IEND 마무리 레코드를 확인합니다.
- 메인 또는 오시는 길 PNG 생성이 실패하면 ZIP 파일을 만들지 않으며, 저장 버튼 비활성화가 정상 복원됩니다.
- 2장 ZIP에 정확히 두 개의 유효한 PNG 파일이 들어가는지 Node 자동 검수를 추가했습니다. ZIP 내부 파일명, CRC32, 중앙 디렉터리 위치도 검증합니다.
- 브라우저 다운로드가 완료됐는지 스크립트에서 확인할 수 없으므로, 기존의 '저장했어요' 대신 '다운로드를 요청했어요. 다운로드 목록 확인'으로 정확하게 안내합니다.
- 오시는 길에는 지도 이미지, 주소, 교통, 주차 안내가 필요하므로 ZIP 저장 버튼 근처에 필수 입력 설명을 추가했습니다.
- 구매 권한 확인, 결제, 토스 환불 및 1회용 복원코드는 변경하지 않았습니다.

## 실제 브라우저 수동 검수
1. 기존 구매자로 로그인하고 프리미엄 6/6 및 '프리미엄 이용 중'을 확인합니다. 새 결제는 하지 않습니다.
2. '초대장 편집기로 이동'에서 프리미엄 디자인 선택, 사진/텍스트 입력 후 오시는 길 탭에서 지도·주소·교통·주차 내용을 완성합니다.
3. '메인 + 오시는 길 · 2장 ZIP 저장'을 눌러 실제 ZIP 파일을 받습니다.
4. ZIP을 열고 `moment_p_..._01_main.png`와 `moment_p_..._02_directions.png`가 모두 열리는지, 사진과 초대 정보·지도 등이 제대로 그려졌는지 확인합니다.
5. 오시는 길 입력이 누락되면 막히는지 확인하고, 입력한 뒤 다시 시도합니다.
6. ZIP 안의 실제 사용 이미지 품질·레이아웃은 브라우저의 수동 검수가 추가로 필요합니다. 자동 테스트가 사용자의 기기에 다운로드 파일이 실제로 저장됐다는 사실을 증명하지는 않습니다.

## 주의
- 판매자가 배포한 것은 아직 TEST 결제 환경입니다. 공개 main 및 LIVE 결제는 변경하지 않았습니다.
- 이미지·구매 권한을 다른 곳에 업로드하지 말고 TEST 안에서 검수합니다.
